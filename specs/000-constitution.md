# 项目宪章（000）

这七条不随需求变化。任何 PR 违反其中一条，直接打回。

## 1. spec 先行
功能需求先写进 `spec.md` 并有可验证的验收标准，才允许进入主链路代码。探索脚本放 `probes/`。

## 2. 只读、本地、不越界
只读用户自己的账号内容；不做点赞、评论、发帖、私信等写操作；不向任何第三方服务器上传用户数据或凭证；服务只监听 `127.0.0.1`。

## 3. 失败必须降级
任何平台 adapter 失败，页面照常可用（显示缓存或标注「该平台暂不可用」），不许白屏、不许整页报错。

## 4. 不逆向签名
平台需要签名时，用浏览器回放让页面自己算（抖音即此方案）。不自研 a_bogus 类算法，不接第三方签名服务作为主路径。

## 5. 单平台可独立验证
每个 adapter 必须能在不启动前端、不连数据库的情况下单独跑通并打印统一结构（`python pull_all.py <platform>`）。

## 6. 演示可恢复
`ONEFEED_DEMO=1` 时必须零网络运行（读 `fixtures/`）。任何功能都要先问「现场断网会怎样」。

## 7. 时间盒
2026-11-27 之后只修 bug，不加功能。11-28 当天只打磨，不开新分支。
