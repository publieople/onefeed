# 004 卡片与界面设计语言

> 版本 v1（2026-11-15）。这份文件把「看起来一致」变成「写得出来、能验收」。
> 实现锚点：`web/tailwind.config.js`（颜色/圆角/阴影）、`web/src/theme.css`（CSS 变量与工具类）、`web/src/components/Card.tsx`（卡片骨架）、`web/src/platform.ts`（平台色）。

## 0. 三条原则

1. **结构优先于装饰**：所有平台、所有形态的卡片共用同一副骨架，差异只体现在「媒体区」和「一行元信息」上，靠结构让人一眼认出来源，不靠渐变或大色块。
2. **缺失就降级，不伪造**：没有封面、没有互动、没有时间，各有明确的降级表现；永远不显示 0、不写「刚刚」、不用彩色块冒充封面。
3. **平台色只做小面积**：平台色是「标签」，不是「主题」。允许出现的位置只有：色点、标签文字/描边/浅底、头像兜底底色、榜单卡渐变底。卡片主体保持白底黑字。

## 1. Token

### 1.1 颜色（固定，不允许在组件里写新色值）

| token | 值 | 用在哪 |
|---|---|---|
| `ink` | #14161A | 标题、主文字、主按钮底 |
| `muted` | #6B7280 | 摘要正文、次要文字 |
| `fade` | #9AA1AB | 元信息（时间、计数、类别）、占位文字 |
| `line` | #E9EAEC | 发丝线、卡片描边、分隔线 |
| `wash` | #F7F8F9 | 页面底、媒体占位底、chip 选中底 |
| `paper` | #FFFFFF | 卡片底、抽屉底 |
| `card` 阴影 | 0 1px 2px rgba(20,22,26,.04) | 卡片静止态 |
| `pop` 阴影 | 0 12px 40px rgba(20,22,26,.10) | 抽屉、浮层 |

平台色（`platform.ts` 唯一来源，插件可用 themeColor 覆盖）：B 站 #00A1D6、小红书 #FF2442、抖音 #FE2C55、掘金 #1E80FF、V2EX #778087、知乎 #0084FF。

平台色的四档透明度（用 `hexAlpha()` 生成，不新增变量）：
- 100%：色点、头像兜底底色、榜单卡渐变起点；
- 28%：标签描边；
- 7%：标签浅底；
- 0%：卡片主体（禁止把平台色铺到卡片背景）。

### 1.2 字号（只允许这些值，禁止 0.5px 步进）

| token | 值 | 行高 | 用在哪 |
|---|---|---|---|
| micro | 11px | tight | 平台标签、类别、计数、时长角标、「N 图」 |
| meta | 12px | tight | 卡片 footer、原因 chip、次要说明 |
| body | 13px | 1.6–1.65 | 卡片摘要、抽屉正文、表单说明 |
| subhead | 15px | 1.4 | 榜单卡标题、抽屉小节标题 |
| title | 16px | 1.42 | 卡片标题（限 2 行） |
| h3 | 17px | 1.3 | 顶栏品牌、抽屉标题 |
| h2 | 19px | 1.25 | 页面标题（市场/设置） |
| h1 | 21px | 1.2 | 抽屉大标题（需要强调时） |
| numeral | 38px | 1.0 | 榜单卡序号 |

字重只有两档：正文 400、标题/强调 500–600。标题统一 `tracking-tight`。

唯一允许的例外：**头像首字 8px**（`Card.tsx` 的 16px 首字块里放一个汉字，11px 会溢出）。除它之外不接受任何 11px 以下的字号。

### 1.3 间距（4px 基准，只允许这些步长）

`2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24`。卡片内边距固定 `12px`（`p-3`），媒体与标题间距 `10px`（`mt-2.5`），标题与摘要 `6px`（`mt-1.5`），footer 上间距 `12px`（`pt-3`）。

### 1.4 圆角（四档 + 全圆）

| token | 值 | 用在哪 |
|---|---|---|
| card | 12px | 卡片、表单卡片、面板 |
| lg | 8px | 媒体容器、输入框、按钮 |
| md | 6px | 小徽章、内层图片格 |
| sm | 4px | 极小的角标（时长、N 图） |
| full | 9999px | chip、色点、头像、标签 |

**新增圆角必须落到上面四档之一**，不要再引入 `rounded-xl` 这类"差不多"的值。

写法的唯一形式：`rounded-card` / `rounded-lg` / `rounded-md` / `rounded`（= 4px，即 sm 档）/ `rounded-full`。不要再写 `rounded-[4px]` 这种任意值——它和 `rounded` 渲染完全一样，只是多一种写法。

### 1.5 图标与动效

- 图标尺寸只有三档：11（行内元信息，如心/评论）、14（媒体上的播放键）、16（占位块）。统一 `lucide-react`，`stroke-width` 默认 2。
- 过渡只有两种：hover 换描边/阴影（`transition`，150–200ms），抽屉滑入。不做缩放、不做渐变入场。

## 2. 卡片骨架（五种形态共用）

从下到上顺序固定，任何新平台都必须落进这副骨架：

1. **头部（`h-5` 固定）**：平台徽章（**实色 pill**：`h-[18px] rounded-full`、平台色底、11px/500 白字）→ 类别（video/images/article/short/list 的中文名，fade 色）→ 右侧相对时间（缺失时退回平台名，不写「刚刚」）。平台只在头部出现一次，footer 不再写「来自 XX」。
2. **媒体区（所有 kind 都有，`aspect-video`，恒定）**：见 §3。任何形态都不许为空——没有封面也要落占位，保证同行等高。
3. **标题**：16px / 600 / 限 2 行，**固定 `h-[46px]`**；榜单卡标题只在正文出现一次，色块内不重复。
4. **摘要 / MetaLine**：**固定 `h-[43px]`**。有正文时显示正文（13px / muted / 限 2 行；short 加 2px 左边框引用）；没有正文时显示首条推荐理由，再没有显示「N 个平台同题」，最后显示「点开详情」。二者占同一块，不叠加。
5. **footer（`mt-auto pt-2.5`）**：头像 16px（无头像用平台色首字块）→ 作者名（最长 52% 宽，超出截断）→ 右侧 点赞 / 评论（只在 >0 时出现，fade 色 + 11px 图标）。
6. **推荐理由不再常驻卡片**：完整理由、同题平台数、簇信息只在抽屉里展示（最多 3 条 chip）。

卡片外壳固定：`rounded-card border border-line bg-white p-3 h-full flex flex-col`，hover `-translate-y-px + shadow-card`（150ms）。**卡片必须写 `h-full`**：容器 `items-stretch`，同一行靠拉伸等高，footer `mt-auto` 沉底——这是 v1.1 对 v1「禁止 h-full」的修正，理由见 §6。

## 2.1 等高契约（v1.1）

- 信息流容器：`grid items-stretch`，禁止 `items-start`。
- 卡片内三段固定高度：header 20px、标题块 46px、MetaLine 43px；媒体区 `aspect-video`（随列宽缩放）。
- 因此**同一视口下所有 kind 的卡片高度完全一致**（1440：380.6px，30/30 卡相同），跨视口的高度差只来自媒体缩放。
- 新增 kind 或新增一行信息时，只能塞进这四段之一，不许在中间插浮动块——否则等高立刻破。

## 3. 五种形态的媒体区

| kind | 媒体区 | 约束 |
|---|---|---|
| video | 16:9 封面，中心播放键（32px 黑透明圆），右下时长角标 | 无封面也占位，保证卡片高度一致 |
| images | 16:9 容器内 1/2/3 列宫格，最多 4 格，第 4 格溢出显示 `+N`，左上「N 图」 | 两列/三列按图片数切，不拉伸不变形；容器仍是 16:9，宫格在内部等比 |
| article | 16:9 左图右文**不单独实现**：用同一副骨架，媒体区为 16:9 缩略图（见 §6 未完成项） | 与 video 共用 Cover，不额外造第七种布局 |
| short | **文字面板**：同一 16:9 块内，平台色 6% 底 + 14% 边、左上引用图标、正文限 4 行 + 底部 14px 渐隐、右下「文字动态 · 平台」 | 不再 `return null`；文字很短也占满 16:9，保证等高 |
| list | 同一 16:9 块内：渐变条铺底（平台色起）→ 52px 序号 → 右侧「热榜 / 442 万热度」 | 渐变只在这里出现；标题不进色块 |

## 4. 占位与降级（缺字段时的唯一表现）

| 情况 | 表现 |
|---|---|
| 无封面 / 封面加载失败 | `NoThumb`：虚线描边块 + 形态图标 16px + 「无封面 · 平台名」（micro、fade）。图片 `onError` 隐藏自己，露出底层占位 |
| 无互动数 | 整块计数不渲染，不显示 0、不显示「—」 |
| 无发布时间 | 头部右侧改为平台名；卡片不出现「刚刚」 |
| 无作者 | 用平台名占位，头像用平台色首字块 |
| 无头像 | 同上，首字块 |
| kind 未知 | 按 short 渲染（纯文字），不报错 |
| 摘要为空 | MetaLine 换成首条推荐理由 / 「N 个平台同题」/「点开详情」，不留空行、不塌高度 |
| 无正文且无理由 | MetaLine 显示「点开详情」 |
| 文字面板内容很短 | 面板仍占满 16:9，底部留白由「文字动态 · 平台」收边 |

## 5. 与其它页面的关系

抽屉、市场、设置共用同一套 token 与骨架逻辑：抽屉标题 17–21px、统计卡 `rounded-lg + wash 底 + 数值 15px/600 + 标签 micro`；市场卡与设置卡沿用 `rounded-card`、`p-4` 内边距、`border-line` 描边。任何页面都不允许自成一套颜色。

## 6. 已知偏差（v1 收口清单）

| 项 | 现状 | 处理 |
|---|---|---|
| 字号 0.5px 步进 | 曾出现 10.5 / 11.5 / 12.5 | 已改成 11 / 12 / 13（本次） |
| `rounded-xl` | 与 card 同值但不同名 | 已改回 `rounded-card` |
| `rounded-[4px]` | 与 `rounded` 同值但不同名（宫格图格） | 已改成 `rounded`（本次） |
| 8px 头像首字 | 唯一低于 11px 的字号 | 列为 §1.2 允许例外，不纳入 AC-D5 扫描 |
| article 的左图右文 | 实际与 video 共用封面布局，spec 曾写 4:3 左图 | 以代码为准，v2 再决定要不要真做左图右文 |
| 列表瀑布流 | 单列网格 + 断点列数（3/2/1），不是 masonry | 记录在案，不改 |
| v1 的「禁止 `h-full`」 | 导致同行卡片按内容高低参差（2.46×） | v1.1 反转：容器 `items-stretch` + 卡片 `h-full` + footer `mt-auto`，见 §2.1 |
| short 无媒体区 | v1 说「整块不渲染」，实测卡片只有别人一半高 | v1.1 改为文字面板，占满同一 16:9 |
| 榜单 112px 固定高 | 与 16:9 无关，横向对不齐 | v1.1 并入 16:9 块 |
| 推荐理由常驻卡片 | 条件渲染 → 卡片高度再变一次 | v1.1 移入抽屉，卡片只留一条 MetaLine |

## 7. 验收（截图存档，逐条对照）

| 编号 | 检查 | 通过标准 |
|---|---|---|
| AC-D1 | 五种 kind 同屏 | 头部顺序、字号、圆角、间距完全一致，只有媒体区不同 |
| AC-D2 | 缺封面条目 | 显示占位块，不像加载失败；卡片高度与有封面条目一致（video 类） |
| AC-D3 | 计数为 0 的条目 | footer 不出现 0 |
| AC-D4 | 平台识别 | 不看媒体也能在 1 秒内说出平台与形态 |
| AC-D5 | 字号/圆角扫描 | `grep text-\[.*\]` 的结果全部落在 §1.2/§1.4 的允许集合内 |
| AC-D6 | 深色主题（--demo 彩蛋） | 只改底色与图片滤镜，不改字号/间距/结构 |
| AC-D7 | 同一视口内全部卡片高度 | 全部相等（1440 = 380.6px，±0.5px），最大/最小 = 1.00× |
| AC-D8 | 平台识别 | 左上角实色 pill 直接给出平台名，不依赖色点或 footer「来自 XX」 |
| AC-D9 | 键盘可达 | Tab 能逐张聚焦、Enter/Space 开抽屉、focus ring 可见 |
