# OneFeed 现状与待解决问题

> 2026-11-15 14:40 实测。数据来自本机运行实例（8788）、仓库提交 `86afbd6`、`tests/run_all.py`。

## 二、必须解决的问题

### P0（不做会影响现场演示或报名）

1. **默认端口被别的项目占用**。实测 8787 现在归 `openmontage` 的 `backlot serve`（PID 48160）；`python -m onefeed` 在 T31 的设计里拒绝静默换端口，会直接退出。现场开机若任何东西占了 8787，演示起不来。→ 演示统一用 `--port 8788`，写进 checklist；或改启动脚本先探测。
2. **没有扫码登录闭环（T43）**。小红书靠 11-14 手工导出的 cookie（`.onefeed/cookies/xiaohongshu.json`，2261 B），抖音没有 cookie。cookie 一过期，演示就少两块内容，且界面上没有「怎么登录」的入口。→ 最低限度做「一键导出 cookie 到 cookies/<id>.json」+ 演示前检查；有余力再做 T43。
3. **登录态判定与数据自相矛盾**。`/api/auth/douyin` 返回 `need_login`，但抖音照常采到 44 条（免登录回放）。chip 显示「需登录」、数据却在，答辩解释成本高。→ auth 改成按「最近一次能否拉到数据」判定。
4. **没有演示清单与录屏（T50/T51）**。没有 `docs/DEMO_CHECKLIST.md`，没有 3 分钟兜底视频，也没按现场流程完整走过两遍。`--demo` 可用，但没人验证过「断网 + 空库 + 装插件 + 拉详情」全链路。
5. **报名材料不齐（11-18 截止）**。报名表缺队名、微信号、两名队员（姓名/学院/专业/年级/分工）；demo 打包 zip 没做；邮件没发（2022874341@qq.com，命名「团队名+队长姓名」）；训练营三场的时间地点仍未知。

### P1（体验和答辩上的硬伤）

6. **详情抽屉没有评论区**。spec T35 要求「有则前 10 条」，现在 API 不返回评论、前端也没渲染；B 站条目有 30 条评论数却看不到一条内容。
7. **统计标签不分场景**。抽屉里所有平台统一「播放/点赞/评论」，掘金文章的 7 次阅读被写成「播放」。
8. **收藏是死按钮**。点了只切本地图标状态，没有持久化，也没有收藏列表。
9. **市场没有更新与版本对比**。T40 只做了安装/卸载/禁用；已装与 registry 版本不同时无法「更新」，也没有提示。
10. **没有设置 API（T44）**。设置页只能看状态和切插件开关，registry 地址、每轮条数、默认排序都改不了。
11. **热度排序把榜单和论坛帖压到底**。按 engagement 取前 100，只剩 video/article/images，short 与 list 消失（知乎热榜没有点赞数）。答辩切「按热度」时，同题合并那组会看不见。spec T46 原计划按平台内分位/z-score，现在是原始计数直排。
12. **缺封面时视觉像 bug**。16 条卡片没有封面，走平台色渐变；images 卡缺图时退化成纯色块，和「加载失败」很难区分。

### P2（工程债，现场可能咬人）

13. **一轮采集 ~90 秒**（B 站 30s+，两个浏览器插件各 15s）。演示前必须先 `--warmup`，否则现场等刷新条。
14. **一个实例有两个 python 进程**（venv launcher + 真实解释器）。按端口提示的 PID 杀进程可能只杀到外壳，残留子进程继续占端口。
15. **fixtures 停在 11-14 23:30**。`--demo` 展示的是那天的数据，演示前要重新 `--warmup` 导出。
16. **没有 CI**。测试只在开发机跑；仓库里有 `.github/` 目录，但没有可确认的 workflow。
17. **插件目录依赖同级 `../onefeed-plugins/plugins`**。换机器要用 `ONEFEED_PLUGINS`，README 有写，但没做成默认自动发现。
18. **依赖系统 Chrome + Playwright**（`channel="chrome"`）。Chrome 大版本升级可能让 browser 能力失效，没有版本检查或降级提示。
19. **数据库没有自动 checkpoint/prune**。`prune()` 只在采集结束时调用，长期开着会累积。
20. **合规口径还没落成文案**。只读、不下载、不代发、不破解签名、插件作者行为与宿主无关——这几句要在 deck 和 README 里固定下来，评委必问。
