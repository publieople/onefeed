## 现场演示顺序（5 分钟）

- 0:00–0:15 开场：七个平台，一屏看完。
- 0:15–1:00 问题：信息被切成七份。
- 1:00–1:50 方案：统一卡片、插件采集、AI 层、关注与自动检查。
- 1:50–3:00 演示：信息流 → 详情页 AI → 刷新胶囊 → 触底自动检查。
- 3:00–4:00 技术：本地优先、插件沙箱、可验证。
- 4:00–5:00 边界、团队、收束。

演示前先跑 `uv run python -m onefeed --preflight`。主演示用真实模式，问题选「这条讲了什么」这类窄问题；不要现场跑宽查询，它会触发主动抓取，实测约 119 秒。
