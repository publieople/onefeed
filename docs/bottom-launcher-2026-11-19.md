# 底部 AI 唤起器：从实心胶囊改成「淡进纸面」

日期 2026-11-19。用户反馈（原话）："那我觉得现在底部这里也得重新设计一下了, 比如可以搞个渐隐的效果之类的, 你觉得呢"，附截图里半透明胶囊横压在卡片上，边缘是一条硬切线。

## 1. 问题在哪

不是胶囊本身丑，是它跟页面没有关系：卡片滚到它下面被一条直线切断，胶囊又是不透明的实心块，看起来像盖了一层贴纸。另外 44→48px 的高度加上 12px 半径的阴影，在整个克制的版式里显得格外重。

## 2. 改了三层

| 层 | 做法 | 文件 |
| --- | --- | --- |
| 底部渐隐 | 胶囊下方铺 `h-28` 的 `from-paper via-paper/85 to-transparent` 渐隐，卡片滚进去淡出 | web/src/agent/AgentSurface.tsx:22-27 |
| 胶囊减重 | 48→44px；`bg-paper/95`→`bg-paper/80`；边框 `border-line`→`border-line/70`；阴影 30px/0.12→14px/0.06；悬停才 `-translate-y-0.5` + 变实 + 阴影加深 | web/src/agent/AgentSurface.tsx:31-40 |
| 内容让位 | 信息流底部 `pb-24`→`pb-32`，最后一行能滚到渐隐层上方，不会被压住 | web/src/pages/FeedPage.tsx:271-273 |

详情页的右下圆钮同步减重（`h-11`→`h-10`、`bg-paper/95`→`bg-paper/85`、阴影减半），但没有加全宽渐隐——详情页底部是「去原帖 / 复制链接」两个按钮，铺一层会把它们吃掉。

## 3. 两个刻意的取舍

- **不用 `backdrop-blur`**：底部条骑在长列表上，模糊要每帧重绘整个视口，正是上一轮性能审计（PF-1）刚拆掉的东西。渐变色带是纯合成层，代价接近零。
- **渐隐层 `pointer-events-none`**：它只是装饰，不能拦点击。实测点一张中心在 y=778（正落在渐隐层里）的卡片，仍然直接进了 `/item/bilibili%3Avideo%3ABV1yRs462EFX`。

## 4. 实测（Chrome 1280×860，8799，库 924 条）

- 胶囊盒：x 260 / y 800 / 760×44；平时 `rgba(255,255,255,0.8)`，悬停 `rgb(255,255,255)`。
- 渐隐层：1280×112 @ y=748，`pointer-events: none`。
- 滚到底：scrollY 3375，最后一张卡 bottom 654 —— 在渐隐层（748）之上，不被压。
- 点穿渐隐层：进详情页成功（见上）。
- 暗色主题：渐变跟随 `--c-paper`，接缝干净。
- 门禁：pytest 82 passed（新增 `test_launcher_fades_into_the_page`）；check-ui 无违规；build 主包 464.42 kB / gzip 151.44 kB。

## 5. 没做

- 滚动时胶囊自动变淡/缩小的"滚动感应"没做：实测这类跟随滚动的浮动条很容易变成噪音，先在截图里看过再说。
- 窄屏（<768）只按行宽推断，没有真机验证；渐隐层高度 112px 在 480 宽下是否偏厚，需要手机上看一眼。
