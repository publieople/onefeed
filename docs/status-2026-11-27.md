## 三、现场演示建议

1. 先跑 `uv run python -m onefeed --preflight`，确认依赖、插件、登录态、端口与网络。
2. 主演示用真实模式，问题选「这条讲了什么」这类窄问题（约 4–12 秒）；不要现场跑「最近有什么进展」这类宽查询，它会触发主动抓取，实测约 119 秒。
3. 演示顺序：信息流七平台 → 详情页 AI 总结 → 右栏 Agent 问这一条 → 顶栏刷新胶囊 / 采集浮层 → 关注名单与作者页 → 滑到底自动检查 → 插件市场。
4. 网络或登录态不稳时，按「90 秒录屏 → 离线 demo → 截图」的顺序兜底。

## 四、已知边界

- 关注名单与作者历史作品补页目前只有 B 站；抖音、小红书、知乎的名单能力未接。
- 离线快照是静态页面，不含 AI 总结、Agent 对话与真实刷新。
- AI 输出可能有误，现场以原文和链接为准。
- 平台条款或页面结构变化可能让某个插件失效；失效会在设置页和采集胶囊里显式提示，不影响其他平台。
