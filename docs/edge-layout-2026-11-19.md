# 贴边三栏改造（2026-11-19）

用户原话（m04216）：

> 其实我之前设想的左右侧边栏是直接吸附在侧边的, 然后中间的信息流直接铺满中间部分,
> 就像这种常规的社交媒体平台的网站这样, 你参考一下, 重新设计我们的前端界面

参考图是 B 站（通栏顶栏 + 顶栏下左侧整高导航 + 六列铺满）、小红书（左导航整高贴左缘、
品牌在栏内）、抖音精选（同构）。

## 改前 / 改后

| | 改前 | 改后 |
| --- | --- | --- |
| 外壳 | `mx-auto max-w-[1820px] gap-5 px-5` 居中容器 | 顶栏通栏 + `flex w-full items-start` 三栏直铺 |
| 左栏 | `rounded-card border`，`sticky top-[76px]`，288 / 64 | 贴左缘 `border-r`，`sticky top-[57px]`，240 / 64 |
| 右栏 | `rounded-card border shadow`，1800 起钉住、默认开 | 贴右缘 `border-l`，1440 起可钉住、**默认关** |
| 中间列 | `max-w-[1180px]` 居中在 1820 壳里 | `flex-1` 吃掉剩余宽度，内部 `max-w-[1400px]` 限阅读宽 |
| 抽屉 | 1280 以上让出 364px（内容被压窄） | 1280 以下固定 340 从顶栏下沿滑出，**不挤内容** |

## 断点（`web/src/layout/useShell.ts`）

| 宽度 | 左栏 | 右栏 |
| --- | --- | --- |
| < 960 | 不渲染 | 抽屉（默认关） |
| 960 – 1199 | 64 图标轨，可点开展开 240 | 抽屉 |
| 1200 – 1439 | 默认展开 240，可收成 64 | 抽屉 |
| ≥ 1440 | 同上 | 可钉住 320（默认关，`]` 打开） |

右栏默认关是为了让信息流真的铺满：它是「稍后再看 / AI」抽屉，不该一直吃掉 320。
跨过 1440 只在小屏方向强制关（防止 340 的抽屉盖半屏），放大时不擅自替用户打开。

## 浮层怎么对齐内容列

底部唤起器、回顶按钮、AI 抽屉都是 `position: fixed`，拿不到两栏宽度就会在整屏里居中，
宽屏上看起来偏在空白里。外壳把两栏实际宽度写成 CSS 变量：

```ts
document.documentElement.style.setProperty("--shell-left-w", leftW + "px");
document.documentElement.style.setProperty("--shell-right-w", rightW + "px");
```

浮层用 `style={{ left: "var(--shell-left-w, 0px)", right: "var(--shell-right-w, 0px)" }}`
把自己夹在内容列上。共享元素代位盒子（`web/src/motion/ghost.ts`）量的是
`[data-content]`（那层带 1400 上限的容器），量不到才退回 `#main`、再退回常量 1400。

## 列数

`web/src/layout/useGridCols.ts`：目标卡宽 380 → 330，取整改成向下取整。

- 900 宽：852 / 330 = 2.58 → **2 列**（四舍五入会硬塞 3 列、每列 270，标题两个字就折行）
- 1280：992 / 330 → 3 列
- 1440：1152 / 330 → 3 列
- 1920：1400 / 330 → 4 列

## 顺手修掉的两处

1. 两栏 `top-14` + `100vh-3.5rem` 会让栏底多出 1px 落到视口外（顶栏 h-14 之外还有 1px 分隔线），
   改成 `top-[57px]` / `100vh-57px`。
2. 抽屉原来 `inset-y-0`，打开时把顶栏右侧的刷新/主题/设置整块盖住，改成从顶栏下沿开始。
